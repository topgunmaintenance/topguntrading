# @topgun/extension

> **Phase 1 scaffold.** No real Chrome MV3 build yet. The MV3 manifest,
> service worker, content scripts, and popup arrive in Phase 5 — see
> `docs/roadmap.md` and `docs/browser-extension-strategy.md`.

The TopGun Trading Chrome extension. A context bridge between the
trader's browser and the workspace. Quick capture, ticker detection,
workspace bridge.

## Phase 5 plan

- Manifest V3
- TypeScript everywhere
- Popup UI from `@topgun/ui`
- Service worker for messaging and refresh
- Content scripts on opt-in origins only
