# @topgun/types

> **Phase 1 scaffold.** Real schemas arrive in Phase 2.

The single source of truth for shared TypeScript types and zod schemas
across web, api, extension, and worker. If a type or schema is used by
more than one app, it lives here.

## Phase 2 deliverables

- `User`, `Session`, `Workspace` schemas
- `Symbol`, `Candle`, `Quote`, `Trade` schemas
- `JournalEntry`, `TradeLog`, `Rule`, `RuleEvaluation` schemas
- `Alert` schemas
- `AIInteraction` schema

Architect (contract), Backend Lead (implementation alongside Prisma).
